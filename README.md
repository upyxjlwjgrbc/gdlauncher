## Overview

GDLauncher is a modern, user-friendly Minecraft launcher that streamlines modpack and mod management with direct integration of the CurseForge and Modrinth libraries, allowing one-click modpack installation, automatic dependency resolution, per-instance Java version management, and a clean interface that replaces the clunky vanilla launcher workflow for modded Minecraft players.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **GDLauncher** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Modpack Library** | Direct CurseForge and Modrinth integration for one-click modpack install |
| **Dependency Resolver** | Automatically downloads and installs all required mod dependencies |
| **Multi-Instance** | Manage multiple separate Minecraft instances each with their own mods |
| **Java Manager** | Per-instance Java version configuration for legacy and modern versions |
